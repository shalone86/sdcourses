# Exported carts

The exact carts behind what is live on kids.methodiusmedia.com:

- Blessed! (exported 2026-11-03): the web game and 1-player downloads from
  `blessed-release.p8`, the 4-player downloads from `blessed4-release.p8`.
  Its code is the same as the repo's at commit 0499159.
- Candles! (exported 2026-11-04): `candles-release.p8` and
  `candles4-release.p8`, read back out of her `.p8.png` carts by PICO-8
  Their code and drawings are the same as `game/nuns/nuns-release.p8`
  at commit 0499159 (PICO-8 only left out the empty sounds), so the
  repo's `game/nuns/nuns.p8` is the source.

Since then (to export next): each player's own score on the 4-player end
screen, everyone picks up the grace piles, the map's "you" dot is blue,
Poor Clare unlocks at 400, and version numbers (Blessed! 1.1, Candles!
1.0).

`*-cart.png` are the cartridge pictures (download cards, Games shelf);
`candles-thumbnail.png` is the Candles! page's sharing picture.
